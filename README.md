# CoinScan Numismatic Identifier website

Static Next.js website for Cloudflare Pages.

## Local run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Cloudflare Pages settings

- Framework preset: Next.js (Static HTML Export)
- Build command: npm run build
- Build output directory: out

The project includes `.nvmrc`, `.node-version`, and `.npmrc` to make Cloudflare use Node 20.12.2 and the public npm registry.
